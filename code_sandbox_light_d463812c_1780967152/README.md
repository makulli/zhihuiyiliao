# 德典健康 - 智慧医疗新生态

一个展示德典健康数字化医疗服务平台的苹果风格企业官网，全面介绍公司业务、合作价值与合作模式。

## 📋 项目概述

这是一个专为德典健康打造的现代化企业展示网站，采用苹果设计语言，通过简洁优雅的界面呈现公司在智慧医疗领域的核心竞争力和业务生态。

### 🎯 项目目标

- 全面展示德典健康的四大核心业务板块
- 清晰传达公司的合作价值主张
- 提供多样化的合作模式介绍
- 打造高品质的品牌形象展示平台

## 🎨 设计规范

### 颜色系统
```css
--primary-color: #007AFF    /* 主色 - 苹果蓝 */
--secondary-color: #5856D6  /* 次色 - 紫色 */
--success-color: #34C759    /* 成功 - 绿色 */
--text-dark: #1d1d1f        /* 深色文字 */
--text-gray: #6e6e73        /* 灰色文字 */
--bg-light: #f5f5f7         /* 浅色背景 */
```

### 渐变系统
```css
--gradient-1: linear-gradient(135deg, #007AFF 0%, #5856D6 100%)  /* 蓝紫 */
--gradient-2: linear-gradient(135deg, #34C759 0%, #00C7BE 100%)  /* 绿青 */
--gradient-3: linear-gradient(135deg, #FF2D55 0%, #FF6B35 100%)  /* 红橙 */
--gradient-4: linear-gradient(135deg, #FF9500 0%, #FF6B35 100%)  /* 橙黄 */
```

### 字体系统
- **标题字体**：Inter, -apple-system
- **正文字体**：Inter, PingFang SC, Microsoft YaHei
- **字重**：300, 400, 500, 600, 700

### 间距系统
- 小间距：8px, 12px, 16px
- 中间距：24px, 32px, 48px
- 大间距：64px, 80px, 120px

### 圆角系统
- 小圆角：8px, 12px, 16px
